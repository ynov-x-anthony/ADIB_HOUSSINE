# Quête 1 – Accessibilité web : enjeux, cadre légal et principes WCAG

## Exercice : principe POUR de chaque critère

1. « Toutes les fonctionnalités doivent être accessibles au clavier. » → **Utilisable**
2. « Les vidéos doivent avoir des sous-titres. » → **Perceptible**
3. « Le code HTML doit être valide, avec des balises correctement imbriquées. » → **Robuste**

## QCM

1. Que signifie RGAA ? → **Référentiel Général d'Amélioration de l'Accessibilité**
2. Niveau WCAG visé par la quasi-totalité des réglementations → **AA**
3. Message d'erreur de formulaire clair → **Compréhensible**
4. Déficience situationnelle → **Une situation temporaire où n'importe qui rencontre des difficultés proches d'un handicap (bras cassé, plein soleil, etc.)**
